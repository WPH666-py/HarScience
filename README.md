# HarScience 0.2.1-rc.38 说明文档（完整使用说明）

## 一、产品概述

HarScience 是一款面向 Windows 的桌面智能体工作台，把大模型对话、科研检索、数据分析、代码执行、CAD 建模、化学编辑和文档写作整合在同一个工作区中。它不是一个只会聊天的窗口，而是一套可以安装插件、切换工作模式、连接本机专业软件、并通过手机继续访问的科研与工程协作环境。

HarScience 的目标，是让用户在一个地方完成从“提出问题”到“交付结果”的完整链路：读题、查资料、拆解任务、编写与运行代码、处理数据、绘制图表、建立三维模型、整理结论、生成报告。过去这些步骤往往分散在浏览器、多个 AI 网站、Jupyter、Python 环境、CAD 软件和 Word 之间，用户需要反复复制粘贴、切换窗口、手动整理格式。HarScience 把这些环节收拢到同一个桌面应用中，让注意力回到问题本身。

当前版本为 0.2.1-rc.38，提供包含完整离线资源的单文件安装包，适合在个人电脑、实验室电脑、教室电脑和临时设备上快速部署。它既可以作为日常学习工具，也可以作为竞赛冲刺、课程项目、科研入门和工程设计阶段的统一入口。

## 二、面向用户

HarScience 主要面向以下人群：

1. 参加数学建模、统计建模、数据分析类竞赛的大学生和研究生。需要快速完成题目理解、资料检索、模型选择、代码实现、结果可视化和论文写作。
2. 需要做课程项目、实验报告、文献综述和毕业设计的本科生与研究生。需要在有限时间内整理资料、形成结构、完成计算和成文。
3. 刚进入科研工作的青年研究者。需要阅读论文、复现实验、处理数据、绘制图表，并把过程整理成可汇报的材料。
4. 学习机械、工业设计、化学、材料等专业的学生。需要用 CAD 或分子编辑工具验证设计想法，但不想先花大量时间学习复杂软件。
5. 需要给课堂、社团或团队做统一环境部署的教师和组织者。希望一台电脑安装一次，学生打开就能用，不依赖外网和复杂配置。

## 三、核心功能

### 1. 多模式对话与工作区

HarScience 以会话为基本单位组织工作。每个会话都有独立的工作目录、上下文和工具权限，可以同时处理多个项目，避免不同任务之间互相污染。界面提供对话、轨迹、文件、工作区等视图，用户可以查看模型每一步做了什么、调用了哪些工具、产生了哪些文件。

应用支持标准模式和专业模式切换。不同模式会挂载不同的提示词、工具集和工作流，用户不需要理解插件配置，只需要选择“我现在要做什么”。对于需要长任务、分步骤推进的科研工作，轨迹视图可以保留完整的推理和执行记录，方便回溯和复盘。

### 2. 数学建模与科研工作流

HarScience 内置了面向数学建模和科研任务的能力组合，包括题目分析、文献检索、模型建议、代码求解、结果解释和论文写作。用户可以把竞赛题目、数据文件、参考文献直接放进工作区，让智能体读取并给出可执行的方案。

在具体任务中，HarScience 可以帮助用户：

- 把一段题目拆成若干可验证的小问题；
- 检索相关方法、论文和数据集；
- 生成 Python 代码并直接运行，读取运行结果；
- 对结果做统计检验、敏感性分析和可视化；
- 按竞赛论文结构整理摘要、问题重述、模型假设、符号说明、模型建立、求解和评价；
- 检查图表编号、公式引用和结论是否前后一致。

相比“在多个网站之间复制答案”，这种工作方式的优势是上下文连续、结果可验证、过程可追踪。代码不是贴在聊天窗口里的文本，而是可以在工作区里真实运行、反复修改的文件。

### 3. 科研检索与论文阅读

HarScience 提供学术检索、论文精读、知识整理等插件。用户可以上传 PDF，让智能体提取研究问题、方法、数据、结论和局限，也可以围绕某个主题做多篇论文的对比。对于需要快速进入一个新领域的学生，这能显著缩短“从不知道看什么”到“知道该看哪几篇、每篇解决什么问题”的时间。

知识画布和笔记能力可以把零散的阅读结果整理成结构化材料，方便后续写综述、开题报告或答辩提纲。

### 4. 自然语言驱动的 CAD 建模

HarScience 集成了参数化 CAD 能力。用户可以用中文描述零件形状、尺寸、孔位、装配关系和工程图要求，系统调用建模工具生成三维模型，并在内置查看器中旋转、缩放、检查。支持草图、拉伸、旋转、放样、扫掠、布尔运算、圆角、倒角、抽壳、阵列、装配、约束和工程图等常用操作。

对于机械、工业设计、材料等专业的学生，这意味着可以先用手绘或文字表达设计意图，再快速得到可验证的三维模型；对于有经验的工程师，重复性的标准件、支架、板件和简单装配可以交给工作流生成，人把时间花在方案比较和关键尺寸上。

HarScience 还可以连接本机的 FreeCAD、Fusion 360、Onshape，以及通过 MCP 连接 AutoCAD 和 SolidWorks。外部软件未安装时，相关能力会给出提示，不影响主程序启动和其它功能使用。

### 5. 科学计算与化学编辑

安装包内置 Python 运行时和常用科学计算依赖，用户不需要自己安装 Conda、配置虚拟环境或解决包版本冲突。数据处理、数值计算、统计建模、图表绘制都可以在工作区直接完成。

化学方向提供分子结构编辑与计算能力，支持绘制结构、导入导出常见化学格式，并结合 RDKit 做性质计算和结构处理。对于化学、药学、材料方向的学生，这减少了在多个专业软件之间转换格式的成本。

### 6. 移动端与局域网访问

HarScience 支持在同一局域网内用手机浏览器访问电脑上的工作区。电脑端打开“移动访问”后，手机会获得一个带密钥的链接，扫码即可进入。手机上可以查看会话、继续对话、阅读结果，适合在教室、实验室、会议现场或通勤途中快速查看进度和补充需求。

移动端界面做了专门适配：两级侧边栏、可滚动的四行导航、按钮避让和触摸操作优化。侧栏第一次点开是指南图标栏，再次点击展开完整内容；展开后按钮固定在品牌栏右侧，不遮挡“新会话”。

### 7. 插件化扩展

HarScience 采用插件化架构，内置 50 余个插件，覆盖学术、数学、化学、CAD、课程、搜索、可视化、办公等方向。用户可以在插件管理中启用、停用和配置插件，也可以安装新的插件包。

插件化带来的好处是：

- 不同用户按需组合能力，不必安装一个固定臃肿的软件；
- 新能力可以独立升级，不牵动整个应用；
- 团队可以维护自己的插件和预设，形成专属工作流；
- 出问题时可以单独停用某个插件，缩小故障范围。

### 8. 离线安装与一键部署

HarScience 提供包含完整离线 seed 的单文件 NSIS 安装包。安装包内置应用程序、运行时、插件依赖和离线资源，用户双击安装即可，不需要预装 Node.js、Python、pnpm，也不需要先下载几十个分片。

安装包按当前用户安装到 `%LOCALAPPDATA%\Programs\HarScience`，自动创建桌面和开始菜单快捷方式。首次启动直接使用内置离线资源；后续启动走已安装快速通道，实测约 18–24 秒进入可用状态。

## 四、典型使用场景

### 场景一：数学建模竞赛的三天

第一天，用户把题目、附件数据和要求放进工作区，让 HarScience 帮忙拆题、检索方法、列出可能的模型和所需数据。第二天，用户选择模型，让 HarScience 生成代码、运行、调参、画图，并把中间结果整理成表格。第三天，用户让 HarScience 按竞赛论文结构生成初稿，自己补充假设、修改表述、检查图表和结论。整个过程在一个工作区完成，不需要反复找文件、贴代码、调格式。

### 场景二：课程项目与实验报告

用户上传实验指导书、原始数据和参考论文，让 HarScience 解释实验原理、整理数据、计算指标、绘制图表，并按照课程要求生成报告框架。用户把精力放在理解实验和解释结果上，而不是重复排版。

### 场景三：机械设计作业与快速验证

用户描述一个支架的形状、孔位和受力要求，让 HarScience 生成三维模型和工程图，检查尺寸和装配关系。方案调整时，只改关键参数，重新生成模型，而不必从草图开始重画。

### 场景四：教师或社团的统一部署

教师在教室电脑上安装一次 HarScience，学生打开就能用；不需要每台机器配置 Python、Node 和插件。没有外网时，内置离线资源仍然可以完成大部分本地任务；需要调用云端模型时再联网。

### 场景五：手机端查看与补充

学生在路上收到老师反馈，用手机打开局域网链接，查看会话进度、阅读结果、补充一句要求，回到电脑后继续执行。移动端不是缩小的桌面，而是围绕“查看、确认、补充”做的轻量入口。

## 五、安装与运行环境

- 操作系统：Windows 10 / Windows 11，64 位。
- 内存：最低 4 GB，建议 8 GB 以上。
- 磁盘：建议预留 3–4 GB。
- 运行时：安装包已内置，无需单独安装 Node.js、Python、pnpm。
- 网络：安装和首次启动可离线；调用云端模型、插件市场、检查更新时需要网络。
- 模型凭证：在应用内设置中配置，或使用 `%USERPROFILE%\.dsh\.credentials.yaml`，也支持 `DEEPSEEK_API_KEY` 环境变量。
- 移动端：电脑与手机在同一 Wi-Fi，浏览器访问电脑显示的局域网链接；防火墙需放行对应端口。

安装包未做代码签名，Windows SmartScreen 可能提示“未知发布者”，选择“更多信息 → 仍要运行”即可。

## 六、快速上手

1. 双击 `HarScience-0.2.1-rc.38-full-setup.exe` 完成安装。
2. 首次启动等待初始化完成，进入工作区。
3. 在设置或模型页面配置 DeepSeek API Key，或登录已有账号。
4. 新建会话，选择工作目录，把题目、数据或文档拖进输入框。
5. 用自然语言描述目标，HarScience 会拆解任务、调用工具并给出结果。
6. 在轨迹中查看执行过程，在文件中查看生成结果，在对话中继续修改。
7. 需要手机查看时，打开“移动访问”，扫码进入。首次使用建议先拿一个小任务熟悉工作区、轨迹和文件视图，再逐步把完整项目交给它。

## 七、数据与隐私

HarScience 的会话、文件和插件数据默认保存在本机 `%LOCALAPPDATA%\Programs\HarScience\data` 下。需要调用云端模型时，相关上下文会发送给所配置的模型服务商；用户应在使用前了解服务商的数据政策。

本地文件、CAD 模型、实验数据和未公开论文是否上传，由用户自己决定。对于敏感项目，建议使用本地模型或关闭不必要的联网插件。

## 十、常见问题

**安装后打不开或一直停在启动页？**
先检查是否被杀毒软件拦截，再查看 `%LOCALAPPDATA%\com.harscience.desktop\logs\harness.log` 的最后几行。如果是旧 profile 导致，退出应用后删除 `%LOCALAPPDATA%\Programs\HarScience\data\profiles\desktop`，重新启动让新 seed 重建。

**手机扫码提示空响应或链接失效？**
应用重启后局域网密钥会变化，请以当前“移动访问”窗口显示的链接为准，或在窗口中重新生成链接。

**没有 SolidWorks / AutoCAD 能用吗？**
可以。主程序和大部分功能不依赖它们；相关插件在缺少本机软件时只会提示不可用，不影响启动。

**一定要联网吗？**
安装和首次启动可以离线；调用云端大模型需要网络和 API Key。本地计算、文件处理、CAD 查看等能力可以离线使用。

**支持 macOS 或 Linux 吗？**
当前版本仅提供 Windows x64 安装包。

## 十一、设计理念与边界

HarScience 的设计遵循四个原则。

第一，本地优先。会话、文件、CAD 模型和插件数据默认留在本机；只有需要调用云端模型时，相关上下文才发送给用户选择的服务商。对于课程作业、实验数据和未公开研究，用户可以选择本地模型或关闭联网插件。

第二，过程可验证。HarScience 不把答案当成黑盒输出，而是把读文件、跑代码、算数据、建模型、画图表的过程放进轨迹。用户可以看到每一步用了什么工具、读写了哪些文件、得到了什么结果，再决定是否接受。

第三，能力可组合。不同专业的需求差异很大，数学建模、化学、机械设计、论文写作并不是同一套工具。HarScience 用插件和预设把这些能力拆开，用户按任务组合，避免被迫接受一个固定流程。

第四，降低环境成本。安装包内置运行时和离线资源，把“装 Python、配环境、找插件、下载模型”这些前置工作收进安装过程，让用户打开软件就能开始任务。

同时，HarScience 有清晰的边界：它不替代用户做最终判断，不保证模型生成的代码、公式、图纸和结论一定正确；涉及安全、医疗、法律、金融等高风险决策时，必须由具备相应资质的人复核。专业软件的使用还需遵守其授权协议。HarScience 的定位是提高资料整理、计算执行和成果表达的效率，而不是替代专业责任。
